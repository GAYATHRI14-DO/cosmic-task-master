# 🚀 Cosmic Task Master

> **A futuristic, gaming-inspired To-Do List that turns your everyday tasks into quests.**

🌐 **Live Demo:** https://questlog-lemon.vercel.app/

---

## 🎮 About

**Cosmic Task Master** is a gamified task management web application designed to make productivity feel like a game.

Instead of simply checking off tasks, users complete **quests**, earn **XP**, increase their level, and track their progress through a futuristic gaming-style interface.

The goal is simple:

**Turn productivity into progression. ⚡**

---

## ✨ Features

* 🎯 Create and manage tasks as quests
* ⚔️ Different quest types and difficulty levels
* ⭐ XP-based progression system
* 🏆 Level-up system
* 📊 Productivity and progress tracking
* 🔥 Active and completed quests
* 🌌 Futuristic dark gaming interface
* 🎮 Gaming-inspired dashboard
* 📱 Responsive design
* ⚡ Fast and modern web experience

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the project

```bash
cd cosmic-task-master
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

* Dark backgrounds
